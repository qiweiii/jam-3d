# JAM machine

A static scene: JAM as a machine in space. Protocol meaning comes from the [Gray Paper](https://graypaper.com/). Other public diagrams are pedagogy, not the spec.

The first view is an establishing shot. Station-by-station STF, formulas, and equation numbers come after the look is locked.

## Run

```bash
pnpm install
pnpm dev
```

Build a static `dist/` (Cloudflare Pages, S3, any static host):

```bash
pnpm build
pnpm preview
```

## Controls

Scroll, arrow keys, or the station list.
